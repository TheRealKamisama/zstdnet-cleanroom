## Reconciled baseline issues and version differences

- Modern Forge injects `FML2` when a suffix is absent. The port preserves the
  original suffix and never introduces modern markers into 1.7.10.
- The old AUTO probe confused a compressed entry's successful raw status reply
  with an ordinary server. The new public status capability distinguishes them.
- A short Zstd frame was consumed as a Minecraft length-prefixed packet. The
  port detects Zstd magic before parsing raw status/login packets.
- Raw status requests leaked per-IP connection slots, active sockets were not
  reliably closed on stop, and an idle timeout was swallowed. Regression tests
  cover the repaired port behavior without changing modern modules.
- Dedicated generated voice defaults contained an unexpanded `${VOICE_PORT}`.
  They now resolve to public 24455/backend 24454. Restricted bind addresses are
  persisted without silently becoming wildcard addresses.
- Runtime supports extra keys absent from the old README: `max_conn_total`,
  `max_req_total_per_window`, `max_worker_threads`, `handshake_timeout`,
  `raw_status_timeout`, and `status_cache_ttl`; the port exposes/documents them.
- The current shared template embeds the download icon inline, while an inherited
  test expected base64 SVG. Port tests now check observable controls/assets rather
  than obsolete CSS/animation snapshots. Warm Sand is the tenth color preset.
- Native 1.7.10 lacks chat COPY_TO_CLIPBOARD and modern Forge TOML configuration.
  Equivalent local copy commands and Forge `.cfg` persistence are used.
- `MinecraftServer` port accessors are SERVER-only in production 1.7.10. LAN
  publication tracks its real bind in ZstdNet's lifecycle service instead.
- Offline backend authentication remains the existing deployment requirement.
  The port does not provide premium-account verification or protocol translation.
