# ZstdNet 1.4.7 — Cleanroom 1.12.2 / Java 25

按照本分支当前参考的上游版本 **1.4.7** 发布，移植版本号为 **1.4.7-cleanroom-1.12.2**。本次统一发行版本命名并补充 CI 上游版本一致性检查；功能代码与此前 `1.4.7-cleanroom-alpha.1` 相同，不表示新增了游戏运行验收。

## 安装与下载

- 需要 Minecraft **1.12.2 / Cleanroom 0.6.10-alpha / Java 25**，不适用于传统 Forge 1.12.2 / Java 8。
- 下载 `zstdnet-1.12.2-cleanroom-1.4.7-cleanroom-1.12.2.jar`，放入客户端及服务端的 `mods`，移除旧版 ZstdNet JAR。
- 提供同名 `.sha256` 校验文件；JNI 已完整内嵌。建议 JVM 参数：`--enable-native-access=ALL-UNNAMED`。
- [安装、配置和构建说明](https://github.com/TheRealKamisama/zstdnet-cleanroom/blob/v1.4.7-cleanroom-1.12.2/mods/1.12.2/zstdnet-cleanroom/README.zh-CN.md)。

## 功能与验证范围

包含 Zstd TCP 压缩代理、UDP 透传、旧 FML 握手、Multiplayer / Direct Connect 接管、HUD、配置界面和流量报告，以及此前的压缩阈值修复。

发布前由 GitHub Actions 执行自动测试、生产 JAR 重映射、内嵌 JNI 完整性校验及独立 JVM 原生压缩往返。此前 Windows x64 生产连接测试及用户实际进服反馈记录在仓库验证文档中；本次 CI 不重跑 Minecraft 游戏验收。

GUI 自动验收、LAN、完整整合包、长时间负载和其他操作系统仍待验证。移除 ZstdNet 版本中的 alpha 后缀不改变这些验证边界，也不改变所需 Cleanroom 加载器的 alpha 版本。
